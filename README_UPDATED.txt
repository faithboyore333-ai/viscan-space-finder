VACANT SPACE FINDER — UPDATED PROJECT

HOW TO OPEN
1. Extract this ZIP file to a folder on your computer.
2. Open that folder in Visual Studio Code (File > Open Folder).
3. Open index.html with Live Server, or open index.html in your browser.
4. The admin dashboard is admin.html.

WHAT WAS UPDATED

- Added Pavilion to the campus map and admin availability venue list.

FUNCTION ROOM RATE CLARIFICATION
The VSU employee/student air-conditioned Function Room rate is set to ₱600 for the first hour, as clarified by the user. The succeeding-hour rate remains ₱350/hour, with a ₱360/hour utility fee.

BOOKING NOTE
This remains a front-end prototype. Booking requests and availability are stored in the current browser only; no request is transmitted to VSU and no booking is officially confirmed.


BOOKING SUBMISSION UPDATE
- Booking requests can now be saved even when the venue's published rates do not produce a complete estimate or optional paid add-ons are not selected.
- Venue-specific selections are saved with the booking request and shown in My Bookings.
- Date, time, unavailable-date, and overlapping-booking checks remain active.
- A successful local submission displays a pending-inquiry message. This front-end prototype stores the request in this browser only; it does not email or transmit it to VSU.
